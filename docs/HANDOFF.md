## 5. 我犯过的错（后人别重踩）

1. `fix box/relax aniso 1e9 vmax …` —— `1e9` 是**目标压力（bar）**，等于 10⁹ bar 压缩，
   盒子必塌、邻居表溢出。正确写法：`fix box/relax aniso 0.0 vmax 0.0002`。
2. hcp 正交胞的 basis 写错（用了 (2/3,1/3,1/2) 或 (0,1/3,1/2)）。**正交胞 (a×a√3×c)
   不能表示 hcp**；hcp 必须用六方/三斜胞，或 2 原子正交胞。用错 basis 会得到
   "能量面乱跳、极小跑到 c/a=1.414" 的假象。
3. 教训：标定必须**打印完整能量面**并检查凸性，不能只取 min。

## 9. 面内共格关系（2026-11-18 推导，建结构按这个来）

Ti(0001) 与 Cu(111) 都是六方排布，最近邻距离：
- Ti: a = 2.950 Å
- Cu(111): a/√2 = 3.650/1.4142 = 2.581 Å
- 比值 2.950/2.581 = 1.1430 = **8/7**（误差 0.03%）

所以取 **7×7 个 Ti 胞 对 8×8 个 Cu 胞**：
- x: 7×2.950 = 20.650 Å ; 8×2.581 = 20.648 Å ✓
- y: 7×(2.950√3) = 35.766 Å ; 8×(2.581√3) = 35.764 Å ✓

即矩形面内盒子 **20.65 × 35.77 Å**，两个方向同时共格，无需人为加应变。
金刚石 C(111) 的面内最近邻 = 3.550/√2 = 2.510 Å，与 Ti 的比 
2.950/2.510 = 1.1753 ≈ 47/40（不够漂亮），C/Ti 界面单独找比值（候选： 
n×2.510 = m×2.950 → 20/17 = 1.176，误差 0.06%，即 17 个 Ti 对 20 个 C）。

层厚建议：C 40 Å / Ti 30 Å / Cu 40 Å / Ti 30 Å / C 40 Å，真空 15 Å 两端。
单界面算例：Cu 60 Å + Ti 60 Å。
